# Human-anchor protocol (depth & preference)

This document defines how the **human anchor** for RQ1/RQ2 is produced and, importantly,
is transparent about what the *currently committed* anchor is and is not.

## TL;DR — what the committed anchor is today

`eval/judges/human_anchor_template.csv` is a **reproducible heuristic proxy**, not a set
of independent human labels. It is generated by `eval/judges/human_anchor.py`
(`score_depth_rubric`), which starts from the LLM judge's depth score and applies
deterministic structural adjustments (penalize repetitive corpus phrasing / TODO
placeholders; reward cross-paper comparison + full evidence linkage).

We label it a *proxy* on purpose so that:

1. the agreement pipeline (Cohen's κ, Spearman ρ, preference agreement) is runnable and
   unit-tested end-to-end without blocking on manual annotation, and
2. the disagreement it surfaces (e.g. human-style penalty for verbose multi-agent output
   that the LLM judge does not apply) is **reproducible** and inspectable in code.

**Do not report the proxy κ as a human-evaluation result.** Report it as a *heuristic
anchor / sanity check*, and clearly mark when numbers come from real annotation instead.

## Producing a real human anchor (recommended for any external claim)

Use `eval/judges/human_anchor_blank.csv` (same schema, no pre-filled scores) and follow:

1. **Sampling** — `scripts/build_human_anchor.py` selects a ~20% stratified sample (one
   topic per domain first, then fill), `repeat=0`. Keep this selection fixed.
2. **De-identification** — present each system's output as **A/B only** (no "multi"/"single"
   labels). Randomize A/B order per item using `EVAL_RANDOM_SEED`.
3. **Two independent raters** — each scores Depth (1–5, see `rubric.md`) and Preference
   (A / B / tie) **without** seeing the other's scores or the LLM judge's scores.
4. **Adjudication** — compute inter-rater agreement (Cohen's κ). For items with a
   ≥2-point depth gap or opposite preference, a third rater adjudicates; record the
   adjudicated value.
5. **Un-blind & record** — map A/B back to multi/single and write the final scores into
   `human_anchor_blank.csv` (rename to `human_anchor_human.csv`).
6. **Agreement vs LLM judge**:
   ```bash
   python scripts/build_human_anchor.py --csv eval/judges/human_anchor_human.csv --json
   ```
   This prints depth κ (multi/single), Spearman ρ, and preference agreement.

## CSV schema

| Column | Meaning |
|--------|---------|
| `sample_id` | `rq1_<topic>_r<repeat>` (matches RQ1 rows) |
| `topic_id` | TopicSet id (e.g. `t01`) |
| `depth_multi_1to5` | Depth score (1–5) for the multi-agent output |
| `depth_single_1to5` | Depth score (1–5) for the single-agent output |
| `preference_multi_single_tie` | `multi` / `single` / `tie` |
| `notes` | Free-text justification (rater id, blind label seen, rationale) |

## Limitations (state these wherever the anchor is cited)

- The committed proxy is **not** an independent human study; it is a deterministic
  heuristic and will agree with the LLM judge by construction except where the structural
  penalties/bonuses fire.
- Real anchors above use **n ≈ 12** (20% of 60 RQ1 rows) — a sanity check on LLM-judge
  bias, not a powered human evaluation. Treat κ as directional.
- Depth is inherently subjective; the rubric reduces but does not remove rater variance.
